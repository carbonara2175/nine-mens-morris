# NINE MEN'S MORRIS

同じ端末を囲んで2人で遊べる、Nine Men's Morris（ナイン・メンズ・モリス）のブラウザゲームです。外部ライブラリやサーバーを使わず、HTML/CSS/JavaScriptだけで動作します。

## Nine Men's Morrisとは

各プレイヤーが9個の石を使う伝統的なボードゲームです。縦横に3個を並べる「MILL」を作り、相手の石を取り除きます。相手を2個以下にするか、移動不能にすると勝利です。

## 遊び方・操作

1. **PLACE**: Player 1から交互に空の交点をタップし、9個ずつ配置します。
2. **MILL**: 3個が一直線に並んだら、黄色く示された相手の石を1個選びます。MILL外の石がある場合はそちらを取ります。
3. **MOVE**: 石を選び、青緑色に示された隣接する空の交点へ移動します。
4. **FLY**: 盤上の石が3個になったプレイヤーは、任意の空点へ移動できます。

画面の案内が次の操作を常に表示します。`RESET GAME`で初期状態に戻せます。

## v1.0の機能

- 同一端末での2人対戦、標準24交点の盤面
- PLACE / MOVE / FLY、MILL成立と石の除去
- 石数・移動不能による勝敗判定
- キーボード操作とスマートフォン向けレスポンシブ表示

## GitHub Pagesで公開

リポジトリの **Settings → Pages** で、公開元を `Deploy from a branch`、ブランチを `main`（または公開するブランチ）、フォルダーを `/ (root)` に設定します。発行されたURLを開くだけでプレイできます。

ローカルでは `python3 -m http.server 8000` を実行し、`http://localhost:8000` を開いてください。ロジックテストは `node test.js` で実行できます。
